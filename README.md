## Deskripsi Program

Program ini dibuat menggunakan algoritma AES (Advanced Encryption Standard) dengan bahasa Python dan library pycryptodome.

## Fitur Program

* Encrypt File
* Decrypt File
* Menggunakan Password/Key
* Menyimpan hasil enkripsi dalam file .enc

## Cara Menjalankan Program

1. Install library:
   pip install pycryptodome

2. Jalankan program:
   python aes_file.py

3. Pilih menu:

   * Encrypt File
   * Decrypt File
